Data deletion — Conch

App: Conch (Android, ai.eight24family.conch).  Developer: Eight 24 Family LLC.

Conch has no hosted backend and no user account. Almost all data stays on your own device or on the SSH servers you connect to. This page explains how to delete it.

1. Delete all data stored on your device

  1. Open Conch.
  2. Go to Settings → Privacy.
  3. Tap “Delete all my data” and confirm.

This immediately and permanently wipes every local store: server records (host / port / user), saved SSH keys and passphrases, cached session histories, and all app preferences. The app then restarts with empty storage. Uninstalling Conch removes the same data.

2. Request deletion of crash & diagnostic data

If optional crash / performance reporting is left enabled (Settings → Privacy → Crash reporting — it is opt-out), a small amount of diagnostic data may have been sent to our error-reporting provider, Sentry. It contains no chat content, no server hostnames or IPs, and no account identifiers.

To request deletion, email nikita@eight24family.ai with the subject “Conch data deletion”. We action such requests within 30 days.

What is deleted vs. retained

  • On-device data — deleted immediately and completely via the in-app button above (or on uninstall). Nothing is retained.
  • Crash / diagnostic data (Sentry) — deleted on request; otherwise automatically purged after Sentry’s retention window of 90 days.
  • Conch keeps nothing else about you on any server we operate — there is no such server.
